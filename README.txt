image-gen-history-summarizer skill 安装与使用说明

安装方式

1. 解压 image-gen-history-summarizer.zip
2. 得到文件夹 image-gen-history-summarizer
3. 把整个文件夹拷贝到你本地的 Codex skills 目录中

最终目录结构需要是：

<你的 CODEX_HOME>\skills\image-gen-history-summarizer\
  SKILL.md
  agents\
  references\

注意：

- 不要只放 .zip 压缩包
- 不要只复制 SKILL.md
- 要把整个 image-gen-history-summarizer 文件夹完整放进去

使用方式

安装完成后，可以直接调用：

$image-gen-history-summarizer

或者：

请使用 $image-gen-history-summarizer 分析这些材料

可用素材

这个 skill 支持输入：

- 聊天记录
- prompt / negative prompt
- 参数截图
- 模型截图
- 多轮结果图
- 带文字说明的截图
- 流程总结长图
- 黑白结构稿
- 彩色进阶稿
- 文件夹路径
- 整套图片目录

适用场景

- 通用 AI 生图复盘
- 图标 / 徽章 / 等级体系 / 黑白到彩色流程复盘
