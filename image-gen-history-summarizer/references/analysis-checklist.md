# Analysis Checklist

在输出前，用这个清单快速检查。

## 1. 盘点输入

- 是否有聊天记录
- 是否有 prompt / negative prompt
- 是否有参数截图
- 是否有结果图
- 是否有文件夹路径或文件夹链接
- 如果有文件夹，是否已将所有相关图片纳入

## 2. 识别材料关系

- 是连续迭代，还是候选分支
- 是否存在中间步骤缺失
- 文件命名是否透露了阶段信息

## 3. 读文字信息

- 是否能读到 prompt
- 是否能读到 negative prompt
- 是否能读到参数、模型名、界面信息
- 是否能读到用户的明确修改指令

## 4. 读图像变化

- 主体有没有变化
- 构图有没有变化
- 风格有没有变化
- 配色有没有变化
- 细节和装饰有没有递增
- 缺陷是否被修正

## 5. 判断输出目标

如果用户更关注：

- “怎么一步一步做出来” -> 输出标准复盘版
- “帮我做成总结图/汇报文案/方法论/提示词” -> 输出沉淀总结版

如果用户没有额外限制：

- 默认输出完整总结版
- 也就是“标准复盘版 + 沉淀总结版”一起输出

## 6. 最后检查

- 是否区分了明确和推断
- 是否说清楚改了什么、为什么改
- 是否把图像变化和文字变化对应起来
- 如果是总结版，是否区分了可复用提示词和项目专用提示词
- 如果是总结版，是否给出了可直接使用的中文组合提示词
- 如果用户没有要求缩短，是否已经输出完整十部分
