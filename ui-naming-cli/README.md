# UI Naming CLI

Independent test tool for generating and validating UI component names.

## Commands

- `ui-naming init`
- `ui-naming generate --role Button --domain Commerce --variant Primary`
- `ui-naming lint .`
- `ui-naming explain UiCommerceButtonPrimary`

## Local Test

1. `cd ui-naming-cli`
2. `npm install`
3. `npm run build`
4. `node dist/src/bin/ui-naming.js --help`
